Introduction

GitHub is a web-based platform built on top of Git, a version control system developed by Linus Torvalds. GitHub allows developers to host their code, collaborate with others, track changes, and manage projects efficiently.

With GitHub, you can store repositories (repos) that contain your source code, documentation, and project files. It simplifies version control by providing visual interfaces for commits, branches, and pull requests. Beyond just code hosting, GitHub also supports documentation (via README.md), automation with GitHub Actions, and website publishing via GitHub Pages.

GitHub is especially powerful for open-source collaboration. It allows multiple contributors to make changes to the same project without overwriting each other’s work, using Git’s branching and merging system. It has become the de facto standard for software version management and collaboration.

  • Track every change in your code (version control)
  • Collaborate with others through pull requests and issues
  • Host your portfolio or documentation via GitHub Pages
  • Automate workflows using GitHub Actions
  • Securely store and manage projects in private or public repos

GitHub Cheat Sheet

This section provides a quick reference on how to set up a GitHub repository and use basic git commands to push your local project to GitHub.

1. Install Git

Install Git using your system package manager:

# Ubuntu / Debian
sudo apt install git

# Fedora / RHEL
sudo dnf install git

# macOS (with Homebrew)
brew install git

2. Configure Git

Set your username and email (used for commits):

git config --global user.name "Your Name"
git config --global user.email "youremail@example.com"

3. Create a New GitHub Repository

Go to https://github.com/new and create a new repository. You can make it public or private, and optionally initialize it with a README file.

4. Link Your Local Folder to GitHub

In your terminal, navigate to your project folder and initialize Git:

cd /path/to/your/project
git init
git add .
git commit -m "Initial commit"

Then connect your local folder to the GitHub repository you just created:

git remote add origin https://github.com/yourusername/your-repo.git

Verify that the remote link is correct:

git remote -v

5. Push Your Code to GitHub

Upload your code to GitHub:

git branch -M main
git push -u origin main

Once completed, your project files will appear on GitHub under your repository’s page.

6. Common Git Commands

  • git status – Check which files are modified or staged
  • git add <filename> – Stage changes for commit
  • git commit -m "message" – Save your changes locally
  • git push – Upload local commits to GitHub
  • git pull – Fetch and merge the latest changes from GitHub
  • git clone <repo-url> – Copy a repository to your local system

Example Workflow

Here’s a minimal end-to-end example of creating a new repo, adding code, and pushing it online: 

# Create and enter a new project
mkdir myproject
cd myproject

# Initialize git and add files
git init
echo "Hello GitHub!" > README.md
git add README.md
git commit -m "Add README"

# Connect to GitHub and push
git remote add origin https://github.com/yourusername/myproject.git
git branch -M main
git push -u origin main

After running these commands, visit your repository page on GitHub — your README file should be visible!
